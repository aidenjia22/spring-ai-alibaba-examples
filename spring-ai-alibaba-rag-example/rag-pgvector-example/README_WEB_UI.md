# 简历分析系统 - Web UI 使用指南

## 概述
基于Spring AI Alibaba的简历分析系统现在提供了完整的Web界面，支持可视化的简历管理和分析功能。

## 系统架构
- **后端**: Spring Boot + Spring AI Alibaba + PgVector
- **前端**: Thymeleaf + HTML5 + CSS3 + JavaScript (ES6)
- **数据库**: PostgreSQL + pgvector扩展
- **AI模型**: 通义千问 (DashScope)

## 功能特性

### 🏠 首页 (/)
- **系统介绍**: 展示系统功能和特色
- **快速操作**: 提供快捷入口
- **系统状态**: 实时显示服务状态和简历统计
- **演示功能**: 一键体验分析功能
- **使用指南**: 详细的操作说明

### 📊 简历分析页面 (/resume)
- **多种上传方式**:
  - 文件上传：支持PDF、DOC、DOCX、TXT格式
  - 拖拽上传：直观的拖拽操作
  - 文本输入：直接粘贴简历内容
- **实时分析**: 上传后自动进行AI分析
- **智能问答**: 基于简历内容的实时问答
- **进度显示**: 清晰的处理进度提示

### 📋 简历管理页面 (/management)
- **列表展示**: 卡片式简历列表
- **搜索筛选**: 按姓名、文件名、状态筛选
- **批量操作**: 支持批量管理
- **详情查看**: 模态框查看详细信息
- **状态管理**: 实时状态更新

## 页面功能详解

## 启动和使用

### 1. 环境准备
```bash
# 确保已安装并启动PostgreSQL (带pgvector扩展)
# 确保已配置通义千问API Key

# 检查配置文件
cat src/main/resources/application.yml
```

### 2. 启动服务
```bash
# 在项目根目录执行
cd spring-ai-alibaba-rag-example/rag-pgvector-example
mvn spring-boot:run
```

### 3. 访问系统
```
主页: http://localhost:8080/
简历分析: http://localhost:8080/resume
简历管理: http://localhost:8080/management
```

## 使用流程

### 基础使用流程
1. **访问首页** → 了解系统功能
2. **上传简历** → 选择文件或输入文本
3. **等待分析** → 系统自动处理
4. **查看结果** → 摘要、详细分析、问答
5. **管理简历** → 查看所有已上传的简历

### 高级功能使用
1. **批量管理**
   - 筛选特定状态的简历
   - 批量删除无用简历
   - 导出分析结果(可扩展)

2. **智能问答**
   - 技能评估问题
   - 经验深度询问
   - 岗位匹配分析
   - 面试问题生成

## API接口说明

### 页面路由
```
GET  /           # 首页
GET  /resume     # 简历分析页面
GET  /management # 简历管理页面
```

### 后端API (与原API保持一致)
```
POST /ai/resume/upload          # 文件上传
POST /ai/resume/import-text     # 文本导入
GET  /ai/resume/list           # 获取简历列表
GET  /ai/resume/analyze/{id}   # 分析简历
GET  /ai/resume/summary/{id}   # 获取摘要
GET  /ai/resume/chat/{id}      # 智能问答(流式)
DELETE /ai/resume/{id}         # 删除简历
```

## 故障排除

### 常见问题
1. **页面无法访问**
   - 检查服务是否启动
   - 确认端口8080是否被占用

2. **文件上传失败**
   - 检查文件格式和大小
   - 确认网络连接正常

3. **分析功能异常**
   - 检查通义千问API Key配置
   - 确认PostgreSQL连接正常

4. **样式显示异常**
   - 检查静态资源路径
   - 清除浏览器缓存
